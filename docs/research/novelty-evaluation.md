# 局部编辑创新与评测备忘（核查日 2026-11-14）

## 最重要结论

“改鼻子以后换视角、做表情仍保留修改”本身已有直接先例。建议把论文问题收窄为：**数值可控的局部三维编辑，如何在开放场景的视频扩散生成中按要求保留，并对编辑大小、区域外变化、动态完成度进行联合验证。** 这仍是待实验验证的候选贡献，不能宣称文献空白。

## 候选创新 1：把“编辑的增量”传进视频扩散，而非只送一张改后参考脸（优先）

研究假设：基础身份条件与明确的局部几何增量分路处理，优于混在同一张参考图/同一 ID embedding 中，尤其在微小改动及大转头时。

实现建议：

1. 存储统一拓扑下的原始网格 V0、改后网格 Va、局部顶点位移 D=Va−V0、语义区域掩码、编辑版本号；姿态和表情参数独立存储。
2. 针对每个目标时刻，用完全相同的姿态与表情渲染改前/改后几何，输出法线、深度、UV、可见性、投影编辑区域、相对几何变化。网格形变、表情、相机均参与投影，不能固定一个正脸二维遮罩。
3. 保留视频模型原有的身份/外观分支，添加小型几何适配器和增量分支，将 delta 的残差限制在几何影响区及合理边界范围。不是宣称空间掩码是新方法，而是检验“带符号、定量增量”的条件能否改善编辑响应。
4. 更新全部身份参考为当前编辑版本；禁止仍把改前完整脸设成硬性的 ArcFace 目标，否则算法可能把用户编辑纠回去。改前资产仅用于定义应保留的外观及非编辑区域。
5. 训练可先用合成/3DGS 渲染的配对编辑视频训练小适配器，冻结大部分视频骨干；再评估到真实感场景的迁移。配对渲染可提供明确几何目标，但不能假装有任意真实场景的成对真实视频 GT。训练域差是主要风险。

必须对比：同一模型、同等参考张数、相同预算的 (a) 当前编辑版本单图参考；(b) 改后多视图参考；(c) 改后逐帧法线/深度；(d) 法线/深度+显式 delta；(e) 再加入局部约束。若 (d) 对 (c) 没有稳定增益，则核心假设不成立。

## 候选创新 2：对视角、表情和可见性自适应的编辑控制（次优先）

研究假设：可见性和局部几何敏感度决定何时、何处加强编辑条件，能比全局恒定强度取得更好的“编辑保持—表情自然”权衡。

方案：在规范 UV/网格坐标中保存编辑；使用目标相机和动画网格计算可见性及重投影；对当前帧能看到的编辑表面注入局部特征，遮挡部分保持资产中的同一几何，不对不可见像素施加形状损失；控制权重可随时间步、区域和姿态变化。用编辑前后两条动画网格的差异定义目标，而不是要求笑脸与中性脸的鼻/颊二维距离完全相同。

必须对比：固定全局权重、固定二维掩码、动态投影掩码、再加可见性和表情相关权重；参考图数量一致。观察极端侧脸转回正脸时修改是否恢复，以及大笑/张嘴是否被抑制。仅仅多视角选图或可见性 gating 单独存在新颖性风险，需进一步对 FantasyID/ViDS 等逐项比对。

## 候选创新 3：面向数值编辑兑现的配对基准（应与方法绑定）

研究假设：现有整体 ID 相似度会遗漏“看起来同一个人但编辑被忽略”，并可能奖励将真编辑纠正回原脸的模型。基准需同时提供数值编辑目标、未编辑区域、视点/表情/镜头分层与失败记录。

协议：同一角色分别做单部位编辑；强度取负/零/正，再扩成多级；每组编辑前/后使用相同提示、动作轨迹、分辨率、采样器及种子。相同 seed 仅减少方差，不保证逐像素对齐。跨镜头使用独立初始化且每次回到角色资产，不沿用上一段输出作新的身份标准。身份划分 train/test；另保留未见的编辑幅度与编辑组合测试。先鼻型、眼距、下颌，后做嘴唇/面颊等与表情强耦合区域。

### 评价不能走的捷径

- 不只看原脸 ArcFace；整体身份可与“改后角色参考”比较，并同时报告与改前的关系。未编辑部分用形状和外观的独立区域度量，不能随意把黑色遮罩脸喂给 ArcFace 并假定分数可靠。
- 不用训练/控制时同一个 3D 拟合器作为唯一裁判：会奖励该拟合器的偏好。用独立地标/拟合模型、已知相机下的渲染 GT、不同视点与人工 A/B 交叉验证；拟合失败也需计入失败率。
- 不直接要求帧间变化越小越好：静止脸会获好分。测量剥离姿态与表情后的几何身份残差波动，同时检验表情强度、头部动作幅度与时序是否达到输入要求。
- 不要求非编辑区域原像素不变：几何编辑会改变轮廓、遮挡、阴影，局部边界和邻域也有合理影响。用规范坐标及形变补偿后度量，明确几何影响区域，单独报告外观泄漏。
- 不在侧脸不可见时把缺失点当几何错误，也不能把失败帧直接丢弃；报告可见帧覆盖率、检测失败率与全片成功率。

### 建议指标

1. 编辑响应：选眼距、鼻翼宽、鼻尖投影、下颌角等可解释量 q；在相同目标姿态/表情下比较 Δq_gen=q(Ia)−q(I0) 与渲染/已知网格目标 Δq_target。报告有符号误差、响应增益与置信区间，不只报相似度。零编辑作假阳性测试，禁止除以零幅度。
2. 剂量曲线：用户滑块逐级增加时，生成测量应单调、幅度合理；报告斜率、偏置、单调违例率，量化是不是只发生一次“换脸”。
3. 泄漏：未编辑区域的规范三维差异减去已知合理目标差异，及经过可见性/形变补偿的外观差异。要避免把整体尺度/相机变化误当编辑。
4. 身份稳定：改后参考的多视角 ID 相似度、跨独立镜头同角色相似度及人工识别；均以辅助指标呈现。
5. 动态完成：独立姿态/表情估计的目标误差、动作幅度与时间曲线；表情估计本身有身份耦合，须人工核对强表情样本。
6. 一致性：剥离动作后的形状残差时序方差、按 UV 对应关系的可见区域漂移；禁止用 raw frame flicker 替代动态正确性。
7. 可用性：编辑兑现且动作完成的片段成功率、检测覆盖率、失败重试数、延迟与显存。阈值需在验证集校准后固定。

首轮可先挑 4 个角色、2 类编辑、3 档强度、3 条固定动作、2 个种子、3 个同骨干方法，共 432 个短片配置；零编辑可缓存复用以省算力。更小的 12–24 条快速冒烟集用于查接线，不能支持论文结论。统计单位是角色或角色×编辑对，按角色分层 bootstrap；不能把同一片的上百帧当上百个独立样本。实际数量应随算力和观测方差调整。

## 选题取舍

优先把贡献写成“开放视频生成中的可量化局部身份编辑传递”，方法主张配合创新 1，创新 2 作为控制模块，创新 3 作为配套评测。不要一开始同时做全身、多角色、任意风格、任意表情和自动修复；这些会掩盖局部编辑是否真正生效。若多视图参考已足够满足目标，则产品可继续推进，但算法论文需要另找相对强基线仍存在的可复现差距。
